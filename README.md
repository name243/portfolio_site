# 💻 Персональный сайт-портфолио веб-разработчика

Красивый, быстрый и адаптивный сайт-визитка, созданный для демонстрации моих навыков, услуг и выполненных проектов. Написан на чистом коде без использования тяжелых конструкторов.

### ✨ Основные особенности

- **Адаптивный дизайн:** Идеально отображается на компьютерах, планшетах и смартфонах.
- **Современный UI/UX:** Темная тема, плавные анимации и стильный неоновый акцент.
- **Чистый код:** Никаких лишних фреймворков — только HTML5, CSS3 и ванильный JavaScript.
- **Оптимизация:** Быстрая загрузка и высокие показатели скорости (PageSpeed).

### 🛠️ Технологии

- **HTML5** — семантическая и доступная верстка.
- **CSS3** — Flexbox, Grid, кастомные переменные и анимации.
- **JavaScript (ES6+)** — интерактивные элементы, мобильное меню и плавный скролл.

### 🚀 Что умеет сайт

- Презентация услуг (визитки, лендинги, интернет-магазины).
- Демонстрация стека технологий (от верстки до натягивания на CMS).
- Форма обратной связи для быстрой связи с клиентом.
